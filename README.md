#C# WPF TimeControl

User interface (UI) component designed for precise time entry and editing, down to milliseconds. The control provides an intuitive and flexible user experience through multiple data input methods.

TimeControl is made under 64bit Windows 10 with Visual Studio 2026 Community Edition.

Key Features
* Precise Time Editing: Supports hours, minutes, seconds, and milliseconds (hh:mm:ss.fff).
* Versatile Input Methods:
  * Keyboard Input: Direct numerical editing of each individual time section.
  * Mouse Wheel (Scroll): Adjusts the value of the selected time section upon hover.
  * Arrow Keys (Up/Down): Precise incrementing or decrementing of the currently active field.
* TimeReset Function: A method that allows quickly resetting the displayed time to its default value (e.g., 00:00:00.000).
* FrameKolor (FrameColor) Function: A property that accepts a Brush type, enabling dynamic color customization of the border surrounding the control (e.g., for validation).
